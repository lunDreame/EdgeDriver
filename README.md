# EdgeDriver

Personal custom SmartThings Edge Driver repository.

## 🧩 Included Drivers

### 📁 [Xiaomi MIoT](./xiaomi-miot)

Xiaomi MIoT – A SmartThings Edge Driver for Xiaomi devices supporting the miIO and MIoT protocol, enabling local control of lights, switches, air conditioners, fans, vacuums, and more.
